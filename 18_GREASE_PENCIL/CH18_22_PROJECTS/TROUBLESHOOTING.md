# CH18.22 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| p1/p2 : « gabarit » refusé | Planche hors convention bcma_board | Partez des starters CH18.12/13 (propriété de scène des cases) |
| p2 : notes non attribuées | Texte hors du bandeau sous la case | Placez chaque note juste sous sa case |
| p3 : « un dessin au début de chaque plan » | Clé GP décalée d'une image du marqueur | Clé exactement à l'image du marqueur (CH18.14) |
| p3 : durée hors 25–35 s | End mal réglé | Frame Range End = dernière image |
| p4/p7 : export refusé | Codec audio ou conteneur | MPEG-4, H.264, AAC (CH18.15) |
| p4/p7 : notes refusées | Format libre | `code · image · remarque` dans REVIEW_NOTES |
| p5 : « dessins par seconde » trop bas | Tenues trop longues partout | Animez au moins en quatre en moyenne |
| p6 : occlusion refusée | Personnage hors du décor ou passe Z coupée | CH18.19 |
| Le projet dérape en durée | Périmètre trop large | Réduisez (plans, personnages) dès le jalon « brouillon » |
| Projet 7 interminable | Tout le board avant l'animatique | Séquence par séquence (LESSON L3 F) |
