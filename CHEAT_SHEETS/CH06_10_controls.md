# Fiche de révision — CH06.10 Contrôleurs et ergonomie

Trois familles : contrôleurs (jamais de déformation), DEF- (déforment, suivent par Copy Transforms), MCH- (cachés). Collections Controls / Deform / Mechanism, les deux dernières masquées.
Formes personnalisées (objets WGT_ dans une collection masquée), couleurs par côté (palettes), verrous (rotation seule pour les bras). Tester le mouvement après chaque rangement.
Correcteur : `--exercise controls [--debug]`.
