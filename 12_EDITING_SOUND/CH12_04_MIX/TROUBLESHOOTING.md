# CH12.04 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| La voix est couverte | Musique trop forte | Volume 0,3 + ducking |
| Pas de ducking | Pas de clés de volume | Animer le Volume |
| Le coup n'est pas à gauche | Pan non réglé | Pan −1 |
| Distorsion | Mixage trop chaud | Baisser les volumes |
| Mixage inaudible | Volumes trop bas | Remonter |
| Clés sur le mauvais strip | Strip sélectionné faux | Cliquer MUSIC |
| Fichiers introuvables | Dossier ASSETS déplacé | Garder la structure |
| Positions changées | Strips déplacés | Les remettre : 1, 49, 61 |
