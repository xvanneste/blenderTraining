Vérifications faites pour ce chapitre dans Blender 5.3.0 : liste des pinceaux de
`datafiles/assets/brushes/essentials_brushes-gp_draw.blend` ; énumérations Stroke Mode
(Stroke/Fill/Both), Caps (Round/Flat), Eraser Mode (Dissolve/Point/Stroke), Line Type
(Line/Dots/Squares), Fill Style (Solid/Gradient/Texture), Layer Mode du Fill ; raccourcis de
l'outil Fill (keymap). Constat : le remplissage est porté par chaque trait (attribut `fill_id`),
les cases Stroke/Fill du matériau ne sont plus dans l'interface.
