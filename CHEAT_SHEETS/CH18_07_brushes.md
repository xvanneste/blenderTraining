# Fiche de révision — CH18.07 Brushes, traits, remplissages

Outil (que fait le clic) · Pinceau (comment) · Matériau (de quoi). Pinceaux = assets (étagère en bas).
Essentials : Pencil, Pencil Soft, Pen, Ink Pen, Ink Pen Rough, Marker Bold/Chisel, Airbrush, Tint,
Fill, Eraser Hard/Soft/Stroke.
Pinceau : Size (`F`, `[` `]`), Strength, pression, **Stroke Mode Stroke/Fill/Both**, Caps Round/Flat.

**5.3 : remplissage = propriété du trait** (Stroke Mode, outil Fill, Edit → Set Stroke Type).
Matériau : panneaux Stroke (Line Type Line/Dots/Squares, Style, Base Color, Holdout) et Fill
(Style Solid/Gradient/Texture, Base Color). `U` = matériau actif.

Outil Fill : clic = remplir · `Ctrl+clic` = inversé · `Alt+glisser` = guide de fermeture ·
Layer Mode (Visible, Active, Layer Above/Below…) · Dilate/Contract · Gap Closure.
Gomme : `Ctrl+clic` ; Eraser Mode Dissolve / Point / Stroke.
Encrage : SKETCH → LINE → COLOR (sous LINE) → SHADE.
