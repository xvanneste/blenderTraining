# CH09.06 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Disque blanc plat | Vue Standard sur une source forte | AgX ou Filmic |
| Image grise et terne | Exposition trop basse | +0,5 |
| Image délavée | Exposition trop haute | Réduire |
| Look introuvable | Les looks dépendent de la vue | Choisir d'abord la vue |
| Mesure différente du viewport | Moteur ou vue différents | Même vue dans le rendu |
| Pixels brûlés persistants | Source trop forte | Réduire l'émission ou l'exposition |
| Noirs écrasés | Exposition trop basse | Remonter |
| Rendu bruité | Peu d'échantillons | 48 minimum |
