# Fiche de révision — CH02.10 Optimisation

Mesurer : Statistics → **triangles** (un quad = 2). Decimate Ratio = part des triangles.
**Decimate** : Collapse (organique, LOD) · Un-Subdivide (subdivision régulière) · Planar (plat).
**LOD** : `Alt+D` (copies liées, même maillage) + un Decimate par objet ; collection LOD.
**Clean Up** (Mesh) : Delete Loose, Decimate Geometry, Degenerate Dissolve, Limited Dissolve, Make
Planar Faces, Split Non-Planar/Concave, Merge by Distance, Fill Holes.
Import : By Distance → Delete Loose → Degenerate Dissolve → `Shift+N`.
Autres : instances, Simplify, textures adaptées, File → Clean Up → Purge Unused Data….
