# CH03.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| La brosse n'a aucun effet | Zone masquée, ou force à 0 | Alt+M (effacer masque) sur une copie ; Shift+F |
| Rien ne se passe sur l'objet | Mauvais objet actif, ou pas en Sculpt Mode | Sélectionnez SCULPT_Head, Ctrl+Tab > Sculpt Mode |
| Le côté opposé ne bouge pas | Mirror X désactivé | En-tête : Mirror X ; sinon Symmetrize |
| Symétrie décalée | Objet tourné/décalé : la symétrie est en espace local | Ne tournez pas l'objet ; Symmetrize |
| Surface « en escalier » | Densité insuffisante pour le détail | Restez aux grandes formes (densité : CH03.03) |
| « Topologie modifiée » au correcteur | DynTopo ou Remesh utilisés | Repartez du starter (ces outils viennent au CH03.03) |
| Le masque a disparu | Alt+M à la fin | Re-masquez l'arrière (il doit rester intact) |
| Pics, trous | Force trop forte, Snake Hook excessif | Ctrl+Z, Smooth (Shift) |
| Viewport lent | Trop de sommets ou d'add-ons | Fermez les autres fichiers ; Simplify ; CH03.03 |
