# Dépannage — Débogage et performance

**Symptôme** Le code optimisé affiche un meilleur temps mais perd des demandes.

**Cause à vérifier** La version rapide a changé le traitement des absences ou l’ordre des résultats.

**Correction** Comparez les sorties et les erreurs sur le même jeu avant de chronométrer.

Refaites le contrôle final. Le compte rendu donne taille, machine, version, temps et égalité du résultat.
