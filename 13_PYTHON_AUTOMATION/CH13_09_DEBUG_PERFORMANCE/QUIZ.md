# Quiz — Débogage et performance

1. Que vérifier avant de comparer les temps ?
   - Le nombre de commentaires
   - La couleur des logs
   - L’équivalence des résultats

2. Que décrit la dernière ligne habituelle du traceback ?
   - Le type et le message d’erreur
   - Le temps total
   - La version de la scène

3. Qu’inclure dans la mesure du dictionnaire ?
   - Les accès seulement dans tous les cas
   - Sa construction et les accès
   - Le temps d’ouverture de Blender

4. Quel défaut explique ce résultat et quelle correction testez-vous ? « Le code optimisé affiche un meilleur temps mais perd des demandes. »
