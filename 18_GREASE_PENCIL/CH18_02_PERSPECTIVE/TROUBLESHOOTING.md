# CH18.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le bâtiment semble « basculer » | Verticales non verticales en 2 points | En 2 points, les verticales restent strictement verticales (outil Line + `Ctrl` pour contraindre l'angle) |
| La boîte paraît déformée, trop longue | PF trop proches de l'objet | Éloigner les PF (hors cadre) |
| Les personnages semblent flotter ou être des géants | Horizon ignoré | Placer les têtes par rapport à l'horizon (THEORY §4) |
| Les fenêtres « glissent » | Lignes tracées à l'œil | Utiliser les fuyantes du GUIDE, ou un calque de construction |
| Trait qui ne part pas droit avec l'outil Line | Accrochage de la souris | Maintenir `Shift` (selon outil) ; ou dessiner à main levée puis lisser |
| Impossible de dessiner sur le calque GUIDE | Verrouillé volontairement | Utiliser les calques USER_ |
