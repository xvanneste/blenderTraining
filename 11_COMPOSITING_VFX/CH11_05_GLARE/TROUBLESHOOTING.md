# CH11.05 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Aucun halo | Pas de Glare ou seuil trop haut | Threshold 1 et valeurs HDR |
| Image noyée | Bloom ou Ghosts | Fog Glow ou baisser Strength |
| Barre droite | Pas de Lens Distortion | Distortion 0,3 |
| Barre sortie de l'image | Distorsion trop forte | ≤ 0,4 |
| Lampe énorme | Halo + distorsion | Réduire Size |
| Cœur gris | Glare qui écrête | Vérifier le cœur ≥ 0,95 |
| Orphelin | Nœud non relié | Supprimer |
| Scène modifiée | Lampe changée | Seulement l'arbre |
