# Exercices — Validation d’une scène

## Exercice guidé

Établir un rapport de contrôle local avec trois anomalies reproductibles. Suivez le [tutoriel](TUTORIAL.md). Joignez le fichier de travail et consignez les trois preuves avec le nom et la version du fichier.

- **Point zéro**. Le terminal affiche zéro anomalie pour la référence.

- **Défauts contrôlés**. Le rapport contient NOM, ECHELLE et IMAGE_ABSENTE avec les noms concernés.

- **Réparation**. Le rapport repasse à zéro et une vue de contrôle compare la silhouette.

## Exercice autonome — Variante

Ajoutez une règle pour signaler les maillages du présentoir qui n’ont aucun matériau. Créez un défaut et un cas valide. Un test de contrôle qualité doit refuser le défaut et accepter au moins un fichier attendu.

**Validation** Un seul message supplémentaire apparaît sur le bloc sans matériau.
