# CH07.15 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le regard saute | FINAL en Constant ou BLOCK active | Bezier et FINAL active |
| La tête dérive pendant l'écoute | Breakdown dans un maintien | Supprimer la clé du maintien |
| Les poses ont changé | Modifications pendant le splining | Revenir aux valeurs de BLOCK |
| BLOCK est modifiée | Travail dans la mauvaise action | Restaurer BLOCK, travailler dans FINAL |
| Les maintiens ondulent | Poignées libres | Auto Clamped |
| Marqueurs sans nom | Renommage oublié | F2 |
| Une action disparaît | Pas d'utilisateur | Utilisateur fictif |
| Mouvement trop brusque | Trop peu de breakdowns | Ajouter des breakdowns |
