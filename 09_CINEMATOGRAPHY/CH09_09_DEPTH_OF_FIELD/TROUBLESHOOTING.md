# CH09.09 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Rien n'est flou | DOF désactivée | Cocher Depth of Field |
| Le sujet est flou | Focus Distance fausse | 5 m |
| Le fond reste net | F-Stop trop grand | 1,0 |
| Tout est flou | Mise au point entre les deux | 5 m |
| Barre proche refusée | Pic < 0,9 | Corriger la distance |
| Mesure instable | Peu d'échantillons | Le correcteur utilise 32 échantillons fixes |
| Caméra modifiée | Focale ou position changées | 200 mm, (0, 0, 0,9) |
| Barres déplacées | Objets bougés | Ne toucher qu'à la caméra |
