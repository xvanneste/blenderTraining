# CH11.04 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Far reste nette | Pas de Defocus ou mauvaise mise au point | Focus Distance 5 m |
| Tout est flou | F-stop trop petit sur toute la profondeur | Augmenter le F-stop |
| Mover nette | Pas de Vector Blur | Ajouter Vector Blur |
| Mover peu étalée | Shutter trop faible | ≥ 0,7 |
| Prise Vector absente | Passe Vector désactivée | Passes > Data > Vector |
| Flou en double | Motion Blur de rendu actif | Le désactiver |
| Scène modifiée | Barres déplacées | Ne pas y toucher |
| Orphelin | Nœud non relié | Supprimer |
