# CH06.08 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le key ne bouge pas | Pas de driver / Value verrouillée | Add Driver sur Value |
| Driver violet | Variable invalide | Objet, bone, type, espace |
| Le key s'applique partout | Pas de groupe | Vertex Group = elbow |
| Valeur > 1 ou < 0 | Curseur non borné | Slider Min 0, Max 1 |
| Gonflage trop fort | Scale trop grand | Réduire (mesure du correcteur) |
| Le key ne change rien au repos... et c'est voulu | Valeur 0 | Normal : il n'agit qu'à la pose |
| Driver en degrés | Unités | Radians : a / 1.5708 |
| Le tube a une forme bizarre au repos | Key actif en Edit | Quittez, Value 0 |
