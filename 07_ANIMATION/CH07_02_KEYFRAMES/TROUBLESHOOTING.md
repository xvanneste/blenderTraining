# CH07.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| La clé n'apparaît pas | Mauvaise propriété ou survol | Survoler la vue 3D, I, choisir la propriété |
| L'objet revient à sa position | Pas de clé à l'image courante | Insérer une clé |
| La caisse dérive pendant le maintien | Valeurs différentes | Clés égales |
| La rotation accélère puis freine | Interpolation Bezier | T > Linear |
| Rendu de 250 images | Plage de fin non réglée | End = 72 |
| Marqueur sans nom | Nom non saisi | F2 |
| Courbe qui dépasse | Poignées non clamped | Auto Clamped |
| Clés décalées d'une image | Mauvaise image courante | Vérifier l'image avant I |
