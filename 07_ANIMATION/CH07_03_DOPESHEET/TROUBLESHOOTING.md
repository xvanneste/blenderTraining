# CH07.03 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Les clés ne bougent pas avec S | Rien de sélectionné ou mauvaise zone | Survoler le Dope Sheet, A, S |
| Les clés tombent à 2, 26, 50 | Pivot à l'image 0 | Curseur à l'image 1 avant S |
| B bouge comme A | Action partagée | Dupliquer l'action |
| L'action s'appelle Slide.001 | Duplication non renommée | Renommer en Slide_Late |
| La fin de l'animation est coupée | Plage trop courte | End = 73 |
| B ne bouge pas | Slot non assigné | Assigner le slot |
| Les valeurs ont changé | Clés déplacées dans le Graph Editor | Annuler ; décaler dans le Dope Sheet (horizontal seulement) |
| Un losange manque | Clé masquée ou non sélectionnée | Montrer tous les canaux |
