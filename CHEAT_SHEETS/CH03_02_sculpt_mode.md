# Fiche de révision — CH03.02 Sculpt Mode

Entrer : Ctrl+Tab > Sculpt Mode. F rayon · Shift+F force · [ ] rayon par pas · Ctrl inverse · Shift lisse.
Brosses : V Draw · C Clay Strips · I Inflate/Deflate · G Grab · K Snake Hook · Shift+C Crease Polish ·
P Pinch/Magnify · Shift+T Scrape/Fill · S Smooth · M Mask.
Symétrie : en-tête Mirror X/Y/Z (espace local) ; Symmetrize.
Masque : M (brosse), B (rectangle), Alt+M effacer, Ctrl+I inverser, Shift+A Expand.
Face Sets : Face Set Paint, Face Sets > Initialize, H cacher, Shift+H isoler (bascule), Alt+H tout, Ctrl+W éditer.
Méthode : grandes formes → secondaires → lissage → détails.
