# Fiche de révision — CH01.06 Transformations avancées

| Action | Raccourci |
|---|---|
| Appliquer (Location, Rotation, Scale, All…) | `Ctrl+A` |
| Menu des orientations | `,` |
| Menu du point de pivot | `.` |
| Snapping on/off | `Shift+Tab` |
| Réglages du snapping | `Ctrl+Shift+Tab` (ou aimant de l'en-tête) |
| Snapping temporaire | `Ctrl` pendant la transformation |
| Menu Snap (curseur/sélection) | `Shift+S` |
| Axe local | `G X X` |

- Scale = multiplicateur ; Dimensions = taille réelle.
- Échelle appliquée (1,1,1) avant rigging, simulation, export.
- Poser sur une surface : Snap Target *Face*, Snap Base *Closest*.
