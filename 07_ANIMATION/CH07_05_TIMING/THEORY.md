# CH07.05 — Cours théorique : Timing et spacing

## 1. Timing et spacing
Le **timing** place les événements dans le temps (images des contacts). Le **spacing** décrit la distance parcourue entre images : en chute libre, les écarts croissent comme 1, 3, 5, 7… (accélération constante) ; à la montée, ils décroissent. Sur une chronophotographie (un point par image), le spacing se lit directement.

## 2. La gravité à 24 images par seconde
g = 9,81 m/s² = 9,81 / 24² = **0,01703 m/image²**. Chute depuis le repos pendant τ images (t = τ/24 s) : h = ½ g t² = **2·h/τ² = a**. Vol de T images entre deux contacts : sommet à mi-chemin, hauteur h = g·T²/8 (a = 8h/T²).

## 3. L'exercice
Lâcher à 2,759 m ; contacts aux images 19, 44, 62 ; sommets à 1,3305 m (image 31,5) et 0,6897 m (image 53) ; repos à partir de l'image 62. Rapports de hauteurs : 0,48 puis 0,52 ; durées de vol : 25 puis 18 images (×0,72). Gravité retrouvée : 0,0170 m/image² pour la chute et les deux vols.

## 4. Poignées
Sommet : tangente horizontale (poignée Auto Clamped). Contact : arrivée et départ raides (poignée Vector : la tangente vise la clé voisine ; ou poignée libre, pente exacte 2h/τ). La solution du chapitre utilise des poignées exactes (une parabole par morceau, 7 clés).

## 5. Mesures
Solution : 39/39. Accélérations médianes d'espacement : −0,0170 pour la chute et les deux vols. Variantes : poignées Vector aux contacts : −0,0142 (accepté) ; Auto Clamped partout : −0,0057 (refusé, flottante) ; linéaire : 0,0 (refusé). Contre-exemples : hauteurs constantes (2,75 m) ; durées égales (25 et 25) ; Z = 0,5 m à la fin ; contacts à −0,12 m.

## 6. Pièges
- Courbe sinusoïdale (poignées horizontales aux contacts) : la balle flotte.
- Hauteur et durée incompatibles avec la gravité (balle trop légère ou trop lourde).
- Oublier le repos final.
- Contacts sous le sol.
- Baker toute l'animation image par image.

## 7. Limites
Balle sans déformation (CH07.01 l'ajoute), sans déplacement horizontal ; trois contacts puis arrêt net (stylisé : une balle réelle ferait des micro-rebonds) ; le correcteur lit la hauteur, pas l'esthétique.
