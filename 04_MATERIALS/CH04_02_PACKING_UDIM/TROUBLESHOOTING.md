# CH04.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| « Tuiles utilisées : [1001] » | Rien n'a été déplacé | Groupe du couvercle : G, X, 1 dans l'éditeur UV |
| Îlot à cheval sur deux tuiles | Déplacement partiel ou incomplet | Sélectionner l'îlot entier (L) avant de le déplacer |
| Tuile en magenta dans la vue | Tuile absente de l'image | Image > UDIM Tiles > Add Tile |
| « Pas de chevauchement » refusé | Îlots superposés | Pack Islands dans la tuile concernée |
| Occupation faible dans une tuile | Un groupe trop petit | Pack Islands avec Scale coché, groupe seul sélectionné |
| Pas d'image UDIM trouvée | Source de l'image ≠ UDIM Tiles | Image Texture > Source : UDIM Tiles |
| Le damier n'apparaît pas | Mode Solid | Material Preview |
| La tuile 1002 s'affiche vide dans l'éditeur UV | Éditeur sur une image non tuilée | Choisir l'image UDIM dans l'éditeur UV |
