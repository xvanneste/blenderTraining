# CH01.12 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Naviguer en vue caméra déplace la caméra | *Lock Camera to View* coché | Décocher (sidebar → View) |
| `Num 0` montre une autre caméra | Caméra active différente | `Ctrl+Num 0` sur la bonne |
| Pas de flou visible | Mode Solid/Material Preview, DOF décoché, F-Stop élevé, sujet loin | Mode Rendered, cocher DOF, F-Stop 1,4–2,8 |
| Tout est flou | Mise au point sur le mauvais objet ou distance | *Focus on Object* = Empty sur les yeux |
| La caméra « saute » quand on la tourne | Contrainte Track To active | Désactiver/supprimer la contrainte, ou tourner la cible |
| Le cadre est très petit dans la vue caméra | Zoom de la vue | `Home` en vue caméra (*View All* ajuste le cadre) |
| Les verticales des bâtiments penchent | Caméra inclinée vers le haut | Garder la caméra horizontale et utiliser *Shift Y* |
