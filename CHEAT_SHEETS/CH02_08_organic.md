# Fiche de révision — CH02.08 Modélisation organique

Blocking (volumes, silhouette) → cage propre → détails (sculpt, textures).
Box modeling : cube + `Ctrl+2`, Mirror (Clip), `O` édition proportionnelle, `Shift+Alt+S` To Sphere,
Cast, Loop Cut là où la forme change, quads.
**Skin** : squelette d'arêtes (E sur sommets), rayon par sommet `Ctrl+A` (Edit Mode), Branch
Smoothing, symétrie X ; boutons du modificateur / `F3` : Skin Root Mark, Mark/Clear Loose, Radii
Equalize, Armature Create. Pile : **Skin → Subdivision** (1/2).
Crédibilité : rythme épais/fin, asymétrie, courbes d'action, échelle.
