# CH00.04 — Périphériques d'entrée

**Phase :** 0 — Préparation et installation  
**Niveau :** débutant  
**Durée estimée :** 1 h  
**Version :** Blender 5.3.0

## Introduction

Blender se pilote à deux mains : une sur la souris, une sur le clavier. Selon votre matériel — souris 3 boutons, trackpad, clavier sans pavé numérique, tablette graphique — certains réglages changent tout. Ce chapitre vous aide à configurer chaque périphérique, à connaître les solutions de remplacement (émulations, gizmo de navigation) et à vérifier la pression de votre stylet, indispensable pour la sculpture, la peinture de textures et Grease Pencil.

## Prérequis

- CH00.02 validé (fenêtre Preferences connue).

## Objectifs pédagogiques

À la fin du chapitre, vous saurez :
1. Utiliser les gestes de navigation standard à la souris 3 boutons.
2. Remplacer le pavé numérique (Emulate Numpad, gizmo, pavé USB).
3. Configurer un trackpad (Emulate 3 Button Mouse, gestes multi-touch).
4. Installer et calibrer une tablette graphique (Tablet API, seuil de pression).
5. Connaître l'intérêt et les limites d'une souris 3D (NDOF).
6. Organiser un poste ergonomique pour des milliers d'heures de pratique.
