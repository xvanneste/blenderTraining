# CH10.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Plafond noir | Diffuse 0 | Diffuse ≥ 2 |
| Image bruitée | Trop peu d'échantillons | Max Samples ≥ 32 et seuil ≤ 0,05 |
| Rendu trop long | Seuil trop bas ou Max Samples trop haut | Seuil 0,02 ; Max 64–256 |
| Adaptatif sans effet | Case décochée | Cocher l'en-tête |
| Points clairs isolés | Lucioles | Voir CH10.03 |
| Mesure refusée | Scène modifiée | Light 20 W |
| Valeurs différentes | Graine ou machine | Comparer les seuils |
| Moteur refusé | EEVEE | Cycles |
