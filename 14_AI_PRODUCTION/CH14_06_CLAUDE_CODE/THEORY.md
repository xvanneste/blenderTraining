# Théorie — Claude Code et Blender

## Spécifier

Les entrées, sorties et refus attendus rendent le code proposé testable.

## Inspecter

Un correcteur de lecture seule peut inspecter les datablocks sans appeler d’édition ni de réseau.

## Tester

Un bon résultat sur un seul fichier ne montre pas que le défaut peut être détecté.

Pour une application directe, suivez le [tutoriel](TUTORIAL.md).

## Cas de production

Un script assisté doit répondre à un contrat avant de passer en production. Pour un outil de lecture, définissez entrées, sorties et effets permis. Un nom de commande plausible ne démontre pas la présence d’une API. Une scène nominale répond à la question du fonctionnement et une mutation nommée répond à celle de la détection d’erreur.
