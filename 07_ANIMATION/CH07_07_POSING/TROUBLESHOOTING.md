# CH07.07 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Les pieds quittent le sol | Hanches basculées sans compensation | Rotation inverse des cuisses |
| La pose paraît raide | Colonne droite | Rotations en cascade (spine, chest, neck, head) |
| Le personnage penche comme un poteau | Épaules et hanches parallèles | Sens opposés |
| Les bras se fondent dans le torse | Bras collés | Dégager les bras |
| Le personnage tombe | Appui hors des hanches | Cheville d'appui sous le centre |
| Rotation dans le mauvais sens | Axe ou signe | Essayer le signe opposé |
| Le bone s'allonge | Échelle accidentelle | Alt+S pour la remettre à 1 |
| La silhouette est un blob | Trop de superpositions | Écarter bras et jambes |
