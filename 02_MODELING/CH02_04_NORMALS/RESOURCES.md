Vérifications faites dans Blender 5.3.0 : opérateurs *Shade Smooth / Shade Auto Smooth / Shade
Smooth by Angle / Shade Flat* (menu Object), menu *Mesh → Normals* (Flip, Recalculate Outside/Inside,
Set from Faces, Average, Point to Target, Set Face Strength), raccourcis `Shift+N` et `Shift+Ctrl+N`,
overlay *Face Orientation*, modes et options du Weighted Normal. Valeurs de normales mesurées sur le
maillage évalué (`mesh.corner_normals`).
