# Fiche de révision — CH18.05 Composition

| Règle | Effet |
|---|---|
| Tiers | équilibre dynamique |
| Lignes directrices | guident vers le sujet |
| Symétrie | ordre, solennité, malaise |
| Diagonale | mouvement, effort |
| Cadre dans le cadre | isolement |
| Espace de regard | confort (inverse = tension) |
| Horizon bas / haut | liberté / écrasement |

Valeurs : 3 suffisent (clair / moyen / sombre). Sujet = contraste maximal. Test des yeux plissés.
Hachures : espacées = clair, moyennes = gris, serrées + épaisses = sombre (ou outil Fill).
Profondeur : premier plan épais et coupé par le cadre / plan moyen = action / fond fin, clair, simple.
