# CH11.06 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Pas de teinte | Mauvaise prise (facteur au lieu de couleur) | Couleur de Lift/Gain |
| Ombres chaudes | Lift orange | Lift bleu |
| Hautes lumières froides | Gain bleu | Gain orange |
| Image trop claire | Gamma ou Gain trop forts | Revenir près de 1 |
| Hautes lumières blanches sans teinte | Écrêtage | Baisser le Gain |
| Orphelin | Nœud non relié | Supprimer |
| Compositing désactivé | Pipeline | Activer |
| Type différent | Offset/Power/Slope | Lift/Gamma/Gain |
