## Exercice 1
`Num 1` (Front) → `Num 3` (Right) → `Num 7` (Top) → `Ctrl+Num 1` (Back) → `Ctrl+Num 3`
(Left) → `Ctrl+Num 7` (Bottom) → `Num 0` (Camera) → orbite `MMB` (repasse en *User
Perspective* grâce à Auto Perspective).

## Exercice 3 (une solution possible)
Activer *Emulate 3 Button Mouse* et *Emulate Numpad* ; orbite `Alt`+glisser ; vue de
dessus `7` ; cadrage : *View → Frame Selected* (menu) ; caméra `0` ; ou tout faire avec le
gizmo de navigation (clic sur Z = dessus, icône caméra = vue caméra, glisser = orbite).

## Leçon 2 difficile (exemple de réponse)
« Active Emulate 3 Button Mouse et Emulate Numpad (Preferences → Input). Orbite :
Alt+glisser ; panoramique : Shift+Alt+glisser ; zoom : Ctrl+Alt+glisser ou pincement. Vues :
chiffres de la rangée du haut, ou clic sur les axes du gizmo. Cadrer : View → Frame Selected.
En Edit Mode, utilise les icônes sommet/arête/face de l'en-tête. »
