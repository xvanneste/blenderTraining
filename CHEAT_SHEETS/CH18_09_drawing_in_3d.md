# Fiche de révision — CH18.09 Dessin dans l'espace 3D

Stroke Placement : Origin · **3D Cursor** · Surface (+Offset) · Stroke.
Drawing Plane : View · **Front (X-Z)** · Side (Y-Z) · **Top (X-Y)** · Cursor.
Curseur 3D : `Shift+clic droit` ; précis : `N` → View → 3D Cursor → Location.
Canvas : Viewport Overlays → Canvas → Use Grid (grille du plan actif) ; Fade Inactive Layers/Objects.

Layout dessiné : caméra d'abord → un calque par plan (GROUND, BG, MID, FG) → curseur à la
distance → dessiner en vue caméra → orbiter pour vérifier. Loin = grand ; proche = petit.
Références : Add → Image → Reference ; File → External Data → Pack Resources.
Organisation : collections SET / DRAWINGS / REFERENCES / CAMERAS / LIGHTS ; Lights des calques ;
passe Z ; scènes (Linked Copy).
Optimiser : Render → Simplify → Grease Pencil (Playback Only…) ; modificateur Simplify.
