# CH05.05 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Couleur uniforme | Noms différents ou Attribute non relié | « height » des deux côtés ; relier Fac |
| Attribut absent du Spreadsheet | Store non relié à la sortie | Chaîner le nœud |
| Valeurs toutes à 0 | Stockage avant Set Position | Stocker après |
| Facettes | Domaine Face | Domaine Point |
| Rampe peu exploitée | Plage de valeurs mal ramenée | Map Range |
| Matériau absent | Set Material manquant | L'ajouter |
| Attribut texte non trouvé | Nom avec espace ou casse | Copier/coller le nom |
| Valeur par face attendue | Mauvais domaine | Domain Face, type adapté |
