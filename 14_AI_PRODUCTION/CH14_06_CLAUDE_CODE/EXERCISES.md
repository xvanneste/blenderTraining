# Exercices — Claude Code et Blender

## Exercice guidé

Vérifier un script assisté sur un cas nominal et des scènes mutées avant de l’utiliser. Suivez le [tutoriel](TUTORIAL.md). Joignez le fichier de travail et consignez les trois preuves avec le nom et la version du fichier.

- **Spécifier**. Le brief fixe version Blender, périmètre de collection et format d’un message.

- **Inspecter**. Le diff répond au brief, et vous justifiez chaque API importante.

- **Tester**. Deux journaux permettent de comparer le cas nominal et le cas fautif.

## Exercice autonome — Variante

Si vous avez une intégration MCP autorisée, comparez une lecture de scène à ce que le script rapporte. Consignez les outils et le périmètre autorisé. MCP est un accès supplémentaire à un logiciel. Le script de ce cours fonctionne également en CLI local.

**Validation** Les deux sorties parlent du même état de scène, ou la variante est documentée comme non réalisée.
