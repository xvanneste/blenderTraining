# Fiche de révision — CH18.14 Du scénario à l'animatique

Chaîne : scénario → découpage → liste de plans → storyboard → animatique.
Temps : images = durée × 24 ; début(n) = 1 + somme des précédents ; End = dernière image.
2D (GP) : une clé par plan sur un calque (Shift+I = Insert Blank Keyframe ; Duplicate Active
Keyframe) · marqueurs M, F2 pour renommer · caméra ortho animée (Orthographic Scale + I).
3D : une caméra par plan · sélection caméra puis marqueur · Ctrl+B Bind Camera to Markers · 180°.
Incrustation : Output Properties > Metadata (Marker, Frame, Camera) + Burn Into Image.
Aperçu : View > Render Playblast. Modèle : File > New > Storyboarding.
