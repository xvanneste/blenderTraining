# Fiche de révision — CH18.02 Perspective

- Horizon = hauteur des yeux (caméra). Parallèles → même point de fuite.
- 1 point : face à l'espace · 2 points : un angle · 3 points : caméra inclinée.
- PF proches = grand-angle (exagéré) · PF lointains = téléobjectif (doux).
- Milieu d'une face : diagonales. Répéter : diagonales successives. Hauteurs : verticale de référence + fuyantes.
- Personnages de même taille : têtes sur l'horizon si caméra à hauteur d'œil.
- Atmosphère : loin = pâle, peu contrasté, traits fins.
- Pro : décor 3D grossier + caméra → dessin GP par-dessus (CH18.19).
