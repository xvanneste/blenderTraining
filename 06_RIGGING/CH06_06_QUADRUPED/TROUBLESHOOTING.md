# CH06.06 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Os hors de la créature | Méta-rig non ajusté | Échelle 1, position 0 ; ajuster en Edit Mode |
| Rig généré trop grand/petit | Échelle non appliquée | Apply Scale avant de générer |
| Patte voisine qui bouge | Poids parasites | Peindre / limiter les groupes |
| Patte qui ne suit pas | Rig décalé | Rig sous la créature |
| Aucun groupe | Parenté au méta-rig | Parenter au rig généré |
| Jarret qui plie à l'envers | Pôle IK | Régler le pôle (CH06.04) |
| Rig lourd | 283 bones | Masquer les collections |
| Générer échoue | Méta-rig invalide | Lire le message |
