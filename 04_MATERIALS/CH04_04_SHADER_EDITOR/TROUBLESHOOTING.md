# CH04.04 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Sphère uniforme | Rampe non reliée ou Mix à facteur constant | Fac du bruit → rampe → Factor |
| Rouille brillante | Metallic constant | Rampe → Metallic |
| Taches illisibles | Scale trop grand/petit | 2–30 |
| Aucune variation dans le rendu | Matériau non assigné ou Mapping Scale à 0 | Vérifier l'assignation et Mapping |
| « nœud orphelin » | Nœud inutilisé | X pour le supprimer ou le relier |
| Base Color reste grise | Result du Mix non relié | Result → Base Color |
| Texture qui « nage » en animation | Coordonnées Generated sur objet déformé | Utiliser Object |
| Aperçu noir | Mode Solid ou monde noir | Material Preview |
