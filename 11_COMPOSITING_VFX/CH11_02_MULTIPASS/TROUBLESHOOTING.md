# CH11.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Rapport 1,17 | Prise Image utilisée | Combined_key et Combined_fill |
| Rapport trop grand | Exposures trop fortes | +1 / −1 |
| Rapport inversé | Signes inversés | KEY +, FILL − |
| FILL éteinte | Groupe oublié | Relier Combined_fill |
| Nœud introuvable | MixRGB supprimé | Mix (ShaderNodeMix) en mode Add |
| Mesure sur image affichée | Compression sRGB | Convertir en linéaire |
| Lampes modifiées | Puissance changée | 60 W |
| Orphelin | Nœud non relié | Supprimer |
