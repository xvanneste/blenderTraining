# CH12.05 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| SRT faux | Faute ou ponctuation | Texte exact |
| Sous-titre en retard | Images fausses | Image = 24 × temps + 1 |
| Sous-titres en haut | Location y trop haute | y ≤ 0,2 |
| Titre illisible | Taille trop petite | ≥ 40 |
| Titre décalé | Location fausse | (0,5 ; 0,5) |
| Export absent | Aucun strip sélectionné | Sélectionner les textes |
| Titre dans le SRT | L'export prend tout | Normal : le correcteur l'ignore |
| Texte coupé | Taille trop grande | Réduire |
