# CH11.03 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Aucune sphère en couleur | Facteur du Mix à 0 ou masque faux | Relier le masque au Factor |
| La mauvaise sphère reste en couleur | Mauvais index | Index 2 |
| Masque inversé | A et B échangés | A = désaturé, B = original |
| Prise Object Index absente | Moteur EEVEE | Cycles |
| Bords crénelés | Anti-Alias désactivé | Activer Anti-Alias ou Cryptomatte |
| Pass Index changés | Objets modifiés | 1, 2, 3 |
| Orphelin | Nœud non relié | Supprimer |
| Image identique | Compositing désactivé | Output > Pipeline |
