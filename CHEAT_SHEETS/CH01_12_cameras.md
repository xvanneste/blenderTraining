# Fiche de révision — CH01.12 Caméras

| Action | Raccourci / menu |
|---|---|
| Vue caméra | `Num 0` |
| Caméra active | `Ctrl+Num 0` |
| Caméra sur la vue | `Ctrl+Alt+Num 0` |
| Naviguer avec la caméra | N → View → Lock Camera to View (décocher après !) |
| Focale | Object Data → Lens → Focal Length |
| Guides | Object Data → Viewport Display → Composition Guides |
| Profondeur de champ | Object Data → Depth of Field → Focus on Object, Aperture → F-Stop |

Focales : 24 (large, déforme) · 35 (naturel) · 50 (normal) · 85 (portrait) · 135+ (compression).
Composition : tiers, lead room, plongée = petit, contre-plongée = imposant.
DOF : F-Stop bas = flou ; plus de flou si focale longue et sujet proche.
