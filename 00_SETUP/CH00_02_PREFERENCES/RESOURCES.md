## Vérification technique (Blender 5.3.0)
Libellés et valeurs par défaut relevés dans les sources de l'interface
(`5.3/scripts/startup/bl_ui/space_userpref.py`) et par l'API (`bpy.context.preferences`) :
Orbit Around Selection (défaut off), Zoom to Mouse Position (off), Auto Depth (off),
Auto Perspective (on), Undo Steps 32, Save Versions 1, Auto-Save 2 min, Relative Paths on,
Copy on Duplicate : Mesh on / Material off, menu ☰ : Auto-Save Preferences, Save
Preferences, Revert to Saved Preferences, Load Factory Preferences.
