# CH07.06 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| La queue bouge d'un bloc | Clés identiques sur tous les bones | Décaler les extrêmes (2 images par bone) |
| La queue paraît détachée | Retards trop longs | 1 à 4 images |
| La queue s'arrête avec la base | Pas de follow-through | Prolonger les clés de 6 images |
| La pointe fouette sans s'arrêter | Pas de stabilisation | Clé de repos à 0° à la fin |
| Le mouvement est mécanique | Pas d'arc, pas de dépassement | Ajouter un dépassement |
| Le bone ne tourne pas | Rotation Mode quaternion | XYZ Euler |
| Rotation autour du mauvais axe | Axe local | Rotation X locale |
| Retards irréguliers | Clés à la main | Compter les images |
