# CH04.02 — Ressources

- Références : aucun ouvrage n'est cité ici faute de titre vérifié ; cherchez la documentation UDIM de votre logiciel de peinture (le format de numérotation est celui des tuiles 1001, 1002…).

  Les libellés des menus Image (*Add Tile*) n'ont pas été relus dans les sources 5.3 pour ce chapitre : vérifiez dans votre interface.
