# Théorie — Validation d’une scène

## Point zéro

Un rapport de production doit préciser son périmètre. Les images intégrées sont disponibles dans le .blend.

## Défauts contrôlés

Une mutation volontaire par règle permet d’identifier ce que signale chaque test.

## Réparation

La réparation doit préserver le résultat visuel. Une échelle appliquée modifie les données locales.

Pour une application directe, suivez le [tutoriel](TUTORIAL.md).

## Cas de production

Un contrôle de scène compare l’état réel à un contrat défini. Les noms et échelles identifient des erreurs différentes. Une texture intégrée et une texture relative peuvent toutes deux être disponibles. La vérification commence par résoudre le chemin selon le fichier ou la bibliothèque, puis confirme la présence de l’image attendue. Le diagnostic propose un choix de correction en fonction du rôle du fichier.
