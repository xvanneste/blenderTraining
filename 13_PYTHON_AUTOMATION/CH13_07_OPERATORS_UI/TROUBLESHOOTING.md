# Dépannage — Opérateurs et interface

**Symptôme** Une deuxième exécution signale que la classe est déjà enregistrée.

**Cause à vérifier** Le script a appelé register deux fois.

**Correction** Appelez unregister sur les classes existantes ou recommencez dans une session propre.

Refaites le contrôle final. Le repère disparaît avec l’annulation et l’action est indisponible en mode Édition.
