# Fiche de révision — CH00.04 Périphériques

| Geste / touche | Action |
|---|---|
| `MMB` glissé | Orbite |
| `Shift+MMB` | Panoramique |
| Molette / `Ctrl+MMB` | Zoom |
| `Num 1 / 3 / 7` | Face / droite / dessus (`Ctrl` = opposé) |
| `Num 5` | Perspective ↔ orthographique |
| `Num 0` | Vue caméra |
| `Num .` | Cadrer la sélection |
| `Home` | Tout cadrer |
| Émulation 3 boutons | `Alt`+LMB orbite · `Shift+Alt`+LMB pan · `Ctrl+Alt`+LMB zoom |

Réglages : Input → Keyboard (Emulate Numpad) · Input → Mouse (Emulate 3 Button Mouse) ·
Input → Touchpad · Input → Tablet (Tablet API, Max Threshold, Softness) · Input → NDOF.
