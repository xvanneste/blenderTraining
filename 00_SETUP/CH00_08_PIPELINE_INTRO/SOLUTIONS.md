## Exercice 1 — les 7 erreurs
1. `sh020` → `sh0020` (4 chiffres). 2. `Plan large` → `WS`. 3. Durée `-10` → valeur positive
(ex. 60). 4. `sq10` → `sq010`. 5. Description vide (sh0050) → décrire l'action.
6. Statut `fini` → `done` (ou autre statut valide). 7. Ordre : `sh0040` avant `sh0030` →
trier les lignes.

## Leçon 1 facile (classement)
Préproduction : écrire, designer, storyboarder, animatique, planifier. Production :
modéliser, texturer, rigger, layout, animer, simuler, éclairer, rendre. Postproduction :
compositer, monter, mixer, étalonner, livrer.
