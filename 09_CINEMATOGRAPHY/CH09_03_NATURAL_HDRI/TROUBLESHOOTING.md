# CH09.03 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| L'ombre part du mauvais côté | Rotation Z | Tourner le Mapping |
| Image trop sombre | Strength 0,3 | 1 |
| Image brûlée | Strength 3 | 1 |
| Pas d'ombre nette | Image 8 bits | HDRI flottante (EXR/HDR) |
| Monde gris uni | Pas d'Environment Texture | Relier la texture |
| Bruit sur l'ombre | Peu d'échantillons | Plus d'échantillons ou Denoise |
| Le fond est visible dans le rendu | Film Transparent décoché | Selon l'intention |
| L'image ne se charge pas | Chemin absolu | Image empaquetée (Pack) |
