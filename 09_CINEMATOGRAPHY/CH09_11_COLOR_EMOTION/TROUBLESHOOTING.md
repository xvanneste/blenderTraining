# CH09.11 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Couleur trop claire | Couleur linéaire confondue avec affichée | Lancez le correcteur pour lire le rendu |
| Tristesse refusée | Teinte hors 190–250° | Bleu-gris |
| Calme refusé | Saturation > 0,5 | Adoucir |
| Joie refusée | Valeur < 0,8 | Éclaircir |
| Teintes confondues | Écart < 25° | Écarter |
| Accent refusé | Valeur et teinte proches | Changer l'un des deux |
| Peur refusée | Fond trop clair | V ≤ 0,2 |
| Plans déplacés | Objets bougés | Ne changer que les couleurs |
