# Fiche de révision — CH01.10 Modificateurs

Properties → Modifiers (clé bleue) → Add Modifier → Generate / Deform / Edit / Normals / Physics.
Pile évaluée de haut en bas · icônes Edit / Viewport / Render · ˅ : Apply, Duplicate, Copy to Selected, Move to First/Last.

| Modificateur | Réglage clé |
|---|---|
| Array | Count, Relative / Constant / Object Offset, Merge |
| Mirror | Axe, Clipping, Merge, Bisect |
| Solidify | Thickness, Offset |
| Bevel | Amount, Segments, Limit Method |
| Subdivision Surface | Levels Viewport / Render |
| Boolean | Operation, Object |

Ordre type : Mirror/Array → Solidify → Bevel → Subdivision → déformations.
Copier une pile sur d'autres objets : `Ctrl+L` → Copy Modifiers. Appliquer rarement.
