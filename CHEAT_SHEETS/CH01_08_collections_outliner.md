# Fiche de révision — CH01.08 Collections et Outliner

| Action | Raccourci / geste |
|---|---|
| Déplacer / lier à une collection | `M` / `Shift+M` |
| Nouvelle collection depuis la sélection (hors scène) | `Ctrl+G` |
| Masquer / tout révéler / masquer le reste | `H` / `Alt+H` / `Shift+H` |
| Parenter / déparenter | `Ctrl+P` / `Alt+P` |
| Sélectionner le contenu d'une collection | Outliner → `RMB` → Select Objects |
| Afficher les interrupteurs | Outliner → filtre → Restriction Toggles |

Interrupteurs : ☑ Exclude (view layer) · ↖ sélectionnable · 👁 vue (temporaire) · 🖥 viewports (global) · 📷 rendu.
Collections BCMA : SET · PROPS · CHARACTERS · LIGHTS · CAMERAS · HELPERS (📷 off).
