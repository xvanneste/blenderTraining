# CH11.07 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le fond reste vert | Pas de Keying ou Key Color fausse | Key Color = vert du fond |
| Fond noir | Pas de nouveau fond | Alpha Over + RGB |
| Contour vert | Contamination | Color Spill ou Keying |
| Sujet troué | Tolérance trop haute | Baisser Tolerance |
| Fond bleu faux | Linéaire contre affiché | Comparer en affiché |
| Orphelin | Nœud non relié | Supprimer |
| Compositing désactivé | Pipeline | Activer |
| Image absente | Image supprimée | Repartir du starter |
