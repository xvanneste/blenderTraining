## Gestes essentiels
| Action | Raccourci |
|---|---|
| Cadrer la sélection | `.` (pavé) — View → Frame Selected |
| Tout cadrer | `Home` — View → Frame All |
| Caméra active = objet sélectionné | `Ctrl+Num 0` |
| Aligner la caméra active sur la vue | `Ctrl+Alt+Num 0` |
| Vue caméra | `Num 0` |
| Sidebar (Clip Start/End de la vue) | `N` → View |
| Orbite (émulation) | `Alt` + clic gauche |

## Réinitialiser
- Préférences seules : menu ☰ → Load Factory Preferences
- Préférences + démarrage : File → Defaults → Load Factory Settings
- Démarrage personnalisé : File → Defaults → Save Startup File
- Diagnostic : `blender --factory-startup`

## À ne pas confondre
Ctrl+Z (mémoire) · .blend1/.blend2 (copies écrasées) · Ctrl+Alt+S (versions durables)
