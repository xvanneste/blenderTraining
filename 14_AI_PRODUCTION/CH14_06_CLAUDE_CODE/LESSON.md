# Leçons — Claude Code et Blender

## L1 — Spécifier

Donnez un brief local pour signaler les objets hors convention, sans renommer ni enregistrer la scène. Utilisez une copie du .blend et des noms fictifs. Enregistrez une première version et comparez-la au résultat attendu. Le brief fixe version Blender, périmètre de collection et format d’un message.

## L2 — Inspecter et validation

Lisez les appels bpy du script. Repérez les mutations, les chemins d’écriture et les imports. Refusez les accès dont ce contrôle local n’a pas besoin. Terminez par le troisième contrôle du [tutoriel](TUTORIAL.md). Deux journaux permettent de comparer le cas nominal et le cas fautif. Passez ensuite au quiz, puis à la variante si les preuves concordent.
