# Leçons — Opérateurs et interface

## L1 — Définir la commande

Ouvrez le script dans Text Editor et repérez bl_idname, poll et execute. Lancez le script une seule fois dans une session neuve. Enregistrez une première version et comparez-la au résultat attendu. Dans la vue 3D, N affiche la catégorie BCMA.

## L2 — Tester le panneau et validation

Placez le curseur 3D hors origine puis cliquez Ajouter un repère. Comparez les coordonnées du nouvel Empty à celles du curseur. Terminez par le troisième contrôle du [tutoriel](TUTORIAL.md). Le repère disparaît avec l’annulation et l’action est indisponible en mode Édition. Passez ensuite au quiz, puis à la variante si les preuves concordent.
