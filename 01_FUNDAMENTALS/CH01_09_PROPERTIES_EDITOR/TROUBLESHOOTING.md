# CH01.09 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| L'onglet Material/Data attendu n'existe pas | L'objet actif est d'un autre type (caméra, empty) | Sélectionner le bon objet |
| Les réglages s'appliquent au mauvais objet | Éditeur épinglé (punaise enfoncée) | Désépingler (icône en haut de l'éditeur) |
| Une valeur a été modifiée par erreur en glissant | Glisser horizontalement modifie la valeur | `Ctrl+Z`, ou `Backspace` au survol (valeur par défaut) |
| Le matériau protégé a disparu | Bouclier posé après le retrait (0 utilisateur à un moment ne suffit pas, mais l'oubli du bouclier oui) | Remettre le matériau, poser le bouclier, enregistrer |
| *Length = Centimeters* n'apparaît pas | *Unit System* = None | *Unit System* = Metric |
| Changer les fps a décalé l'animation | Les clés restent sur les mêmes numéros d'image | Fixer les fps avant d'animer (ou *Time Remapping*, phase 7) |
