# CH06.04 — Exercices

## Exercice 1 — Facile : choisir ⏱ 15 min
IK ou FK pour : poser la main sur une table ; balancer le bras en marchant ; planter un pied au sol ; lancer une balle ? (Réponses : IK ; FK ; IK ; FK.)

## Exercice 2 — Moyen : le bras IK/FK ⏱ 3 h
Partez du starter, posez IK, pôle, stretch 0 et driver. Validation : `--exercise ikfk`.

## Exercice 3 — Difficile : la jambe ⏱ 3 h
Construisez une jambe (thigh, shin, foot) IK avec pôle de genou et interrupteur ; mesurez les mêmes grandeurs (contact du pied, côté du genou, longueurs).

### Grille d'auto-évaluation (sur 10)
| Critère | 0 | 1 | 2 |
|---|---|---|---|
| IK : cible, pôle, Chain Length 2 | non | partiel | oui |
| Pole Angle calibré (coude vers le pôle) | non | partiel | oui |
| Aucun étirement, bras tendu hors de portée | non | partiel | oui |
| Driver ik_fk : IK à 1, FK à 0 | non | partiel | oui |
| Quatre poses testées à la main | non | partiel | oui |
**≥ 7/10** : acquis.

## Défis
- **Défi 1 :** ajoutez un contrôleur de main FK qui suit le bout en mode FK.
- **Défi 2 :** « snap » IK→FK par script (copier les poses d'un mode dans l'autre).
