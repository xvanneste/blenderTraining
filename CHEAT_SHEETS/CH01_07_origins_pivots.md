# Fiche de révision — CH01.07 Origines, pivots, curseur

| Action | Raccourci / menu |
|---|---|
| Placer le curseur | `Shift+RMB` |
| Menu Snap (curseur ↔ sélection) | `Shift+S` |
| Curseur à l'origine du monde (+ vue) | `Shift+C` |
| Déplacer l'origine | Object → Set Origin → Origin to 3D Cursor |
| Éditer seulement l'origine | Options → Transform → Affect Only → Origins |
| Point de pivot | `.` : Median Point · Bounding Box · 3D Cursor · Individual Origins · Active Element |

Recette « charnière » : Edit Mode, sommets de la charnière → `Shift+S` Cursor to Selected →
Object Mode → Set Origin → Origin to 3D Cursor → `R Z 90`.
