# Fiche de révision — CH02.05 Hard Surface

Arête cassée 1–3 mm / chanfrein (1 segment) / arrondi (3–6 segments).
**Bevel modificateur** : Width, Segments, Profile, Limit Method (None, **Angle**, **Weight**,
Vertex Group), Clamp Overlap, Outer Miter, Shading → **Harden Normals** (+ Shade Smooth).
Poids : Edit Mode → Edge → **Edge Bevel Weight** (pas de raccourci) ; overlay **Bevel** pour voir.
Recette : Bevel « Weight » (arrondis choisis) + Bevel « Angle » 30° fin (2–3 mm, Harden Normals).
Échelle d'objet à 1 (`Ctrl+A`) · détails : Inset + Extrude, pièces jointes `Ctrl+J`.
`Ctrl+L` → Copy Modifiers pour réutiliser la recette. Hiérarchie : grand → moyen → petit.
