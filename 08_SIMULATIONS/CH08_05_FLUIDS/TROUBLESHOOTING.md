# CH08.05 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le domaine est vide | Source non déclarée Flow ou de gaz | Flow Type Liquid |
| Le liquide est grossier | Résolution basse | 32 ou plus |
| Aucune surface | Maillage non cuit | Bake Mesh après Bake Data |
| Le liquide s'arrête trop tôt | Cache court | 1–20 |
| Rien ne tombe | Source hors du domaine | Source dans le domaine |
| Le liquide sort du domaine | Domaine trop petit | Agrandir le domaine |
| Bake très long | Résolution haute | Tester à 32 |
| Fichier lourd | Cache dans le .blend | Cache sur disque |
