# Fiche de révision — CH01.05 Edit Mode

| Action | Raccourci |
|---|---|
| Object ↔ Edit | `Tab` (menu des modes : `Ctrl+Tab`) |
| Sommets / arêtes / faces | `1` / `2` / `3` |
| Boucle / anneau | `Alt+LMB` / `Ctrl+Alt+LMB` |
| Connecté sous la souris / sélection connectée | `L` / `Ctrl+L` |
| Agrandir / réduire la sélection | `Ctrl+Num +` / `Ctrl+Num −` |
| X-Ray | `Alt+Z` |
| Extruder | `E` (menu : `Alt+E`) |
| Aligner sur un axe | `S X 0` |
| Fusionner | `M` |
| Supprimer / dissoudre | `X` |
| Édition proportionnelle | `O` (rayon : molette) |
| Recalculer les normales | `Shift+N` |
Toujours **sortir d'Edit Mode** avant d'enregistrer/rendre.
