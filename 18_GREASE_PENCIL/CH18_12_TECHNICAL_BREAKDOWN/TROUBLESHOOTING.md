# CH18.12 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le texte est invisible en vue caméra | Texte couché (face vers le haut) | `R X 90` : face à la caméra (axe −Y) |
| Taper au clavier déclenche des raccourcis | Pas en édition de texte | Sélectionner le texte, `Tab` |
| Annotation refusée | Élément manquant (valeur, mouvement ou durée) | Format : `SQ010_SH0020 · PM · travelling avant · 4 s` |
| « Une annotation sous chaque case » refusée | Texte placé hors du bandeau | Le placer juste sous sa case |
| Case sans dessin | Traits sur un autre calque | Calque USER_Drawing |
| Le texte se rend mal (pixellisé, mal placé) | Taille ou position | `S` ≈ 0,14 ; vérifier en `Num 0` |
| Flèches confondues | Même style caméra/personnage | Tirets = caméra, plein = personnage |
