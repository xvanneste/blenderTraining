# Quiz — Gestion des assets

1. Que donne la commande Link ?
   - Une copie entièrement indépendante
   - Une dépendance vers une bibliothèque Blender
   - Un fichier vidéo

2. Que modifier avec un override ?
   - Tous les plans source d’un coup
   - L’extension du MP4
   - Une propriété locale sur un élément lié

3. Qu’inscrire dans la feuille de dépendances ?
   - Identifiant, version et plan utilisateur
   - Seulement le nom visible de l’objet
   - Le nombre de tests du cursus

4. Quel défaut explique ce résultat et quelle correction testez-vous ? « Le plan ne retrouve plus l’actif après avoir changé de dossier. »
