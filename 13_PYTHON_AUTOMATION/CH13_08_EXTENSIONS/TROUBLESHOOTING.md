# Dépannage — Extensions Blender

**Symptôme** L’installation échoue alors que les sources fonctionnent via Run Script.

**Cause à vérifier** Le manifeste se trouve dans un sous-dossier de l’archive manuelle.

**Correction** Utilisez la commande extension build et contrôlez la racine de l’archive.

Refaites le contrôle final. Le panneau est utilisable après activation et disparaît après désactivation.
