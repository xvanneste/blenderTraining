# CH10.06 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Valeur relue 1000,5 | 16 bits | Color Depth 32 |
| Valeur relue 1001,5 | DWAA | ZIP |
| Pas de passe Depth | Passe Z désactivée | Passes > Data > Z |
| Fichier monocouche | Type de média | Multicouche |
| Réglages perdus | Changement de type de média | Revérifier profondeur et codec |
| Fichier énorme | NONE ou 32 bits inutiles | ZIP/PIZ |
| Valeurs plafonnées à 1 | PNG ou 8 bits | EXR |
| Scène modifiée | Émission changée | Ne toucher qu'à la sortie |
