# CH05.10 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Blender gèle en changeant Density | Pas de borne | Max 5 |
| Fichier énorme | Instances réalisées, cône lourd | Garder les instances, 8 côtés |
| L'objet disparaît avec l'outil | Entrée ignorée | Join avec Group Input [Geometry] |
| L'outil n'apparaît pas comme modificateur | is_modifier désactivé | Option Modifier |
| Asset introuvable | Pas de catalogue ou bibliothèque non déclarée | Catalogue + Preferences > File Paths |
| Catalogue non reconnu | Fichier à un autre endroit | blender_assets.cats.txt à côté du .blend |
| Matériau manquant sur un autre fichier | Matériau non embarqué | L'ajouter à la bibliothèque |
| Tags absents | Non renseignés | Panneau d'asset |
