# CH05.01 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Rien dans la vue | Group Output non alimenté | Relier la dernière géométrie à Group Output |
| Terrain plat | Offset non relié ou nul | Noise → … → Combine XYZ [Z] → Offset |
| Surface blanche | Pas de Set Material | Ajouter Set Material |
| Facettes visibles | Pas de Set Shade Smooth | L'ajouter |
| Relief anguleux | Grille grossière | Vertices 100 × 100 |
| Relief énorme | Amplitude trop grande | Multiply 2 |
| Terrain sous le sol | Relief centré sur 0 | Relever l'objet |
| Valeurs introuvables | Pas d'inspection | Spreadsheet, Viewer |
