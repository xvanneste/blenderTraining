# CH11.01 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| L'image n'a pas changé | Compositing désactivé | Output > Pipeline > Compositing |
| Image trop sombre | Exposure à 0 | Augmenter la prise Exposure |
| Image granuleuse | Pas de flou | Blur 3 px |
| Sujet effacé | Blur trop fort | Réduire Size |
| Nœud inutile | Non relié | Supprimer |
| Pas de sortie | Group Output non relié | Relier à Group Output |
| Nœud Gamma introuvable | Supprimé en 5.3 | Utiliser Exposure ou Color Balance |
| Scène modifiée | SUN changé | Seulement l'arbre |
