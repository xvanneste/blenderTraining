# Fiche de révision — CH18.12 Découpage technique

Plan = code `SQ010_SH0010` (de 10 en 10) · valeur · angle · mouvement · durée · action/son.
Note normée : **`SQ010_SH0020 · PM · travelling avant · 4 s`**.
Planche : en-tête (projet, séquence, Page 01, version), cases au format du film, bandeau de notes.
Flèches : **tirets = caméra** (travelling avant : coins → centre ; pano : au-dessus ; grue : à côté),
**plein = personnage**. Une case se lit en 1 s.
Blender : gabarit GP (GUIDE verrouillé), USER_Drawing, USER_Arrows, Add → Text (`Tab`, `R X 90`),
`TXT_SH0010`, `TXT_Header`.
