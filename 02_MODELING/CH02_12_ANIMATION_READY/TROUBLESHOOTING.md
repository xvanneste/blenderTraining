# CH02.12 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Coude écrasé ou vrillé | Trop peu de boucles au pli | 3+ boucles serrées autour de l'articulation |
| Loop Cut impossible autour du bras | Anneau interrompu (triangle, n-gon) | Réparer la topologie (CH02.01) |
| Nouvelles boucles mal déformées | Poids non interpolés (boucle tracée autrement qu'au Loop Cut) | Utiliser Loop Cut ; repeindre les poids (phase 6) |
| Fichier enregistré plié | Pose non remise à zéro | Pose Mode, `A`, `Alt+R` / `Alt+G` |
| Le correcteur refuse l'échelle | Bras mis à l'échelle en Object Mode | `Ctrl+A` → Scale |
| `Ctrl+Tab` ouvre un menu | Objet maillage actif | Sélectionnez l'armature d'abord |
