# CH01.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le zoom n'avance plus | On s'approche du pivot sans le dépasser | `Num .` sur l'objet visé ; `Shift+MMB` ; ou Walk |
| La vue « tourne bizarrement », l'horizon se penche | *Orbit Method* = Trackball | Preferences → Navigation → Orbit Method = Turntable |
| Tout a disparu sauf un objet | Vue locale active (nom de vue suivi de *(Local)*) | `Num /` |
| Une partie de la scène est coupée | *Clipping Region* (`Alt+B`) active | `Alt+B` |
| `Ctrl+Alt+Num 0` déplace la mauvaise caméra | Elle agit sur la **caméra active** | `Ctrl+Num 0` d'abord sur la bonne caméra |
| En vue caméra, naviguer déplace la caméra | *Lock Camera to View* activé | Sidebar `N` → View → décocher |
| La caméra orthographique montre un objet minuscule ou coupé | *Orthographic Scale* inadapté | Ajuster la valeur (largeur visible en mètres) |
| La touche `` ` `` n'existe pas (AZERTY) | Disposition clavier | Gizmo de navigation, ou réassigner dans Preferences → Keymap (« View Pie ») |
