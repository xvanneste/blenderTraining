## Exercice 3 — Difficile : un escalier ⏱ 4 h
Écrivez une sixième fonction `staircase(n)` qui crée n cubes montant d'un cube à chaque pas (x = i, z = i) en réutilisant make_cubes et un calcul de positions ; regardez le rendu.

**≥ 7/10** : acquis.

## Défis

- **Défi 2 :** make_cubes avec une taille variable selon l'indice.
