# Fiche de révision — CH03.04 Sculpture stylisée

Intention → forme dominante (cercle doux · carré fort · triangle dangereux) → contrastes (grand/moyen/petit,
droit/courbe, simple/détaillé) → silhouette lisible face ET profil.
Blocage : ellipsoïdes qui se chevauchent + Join + Voxel Remesh ; ou métaballes (Add > Metaball,
Negative pour creuser, Object > Convert > Mesh) ; Boolean Difference pour orbites.
Socle : Mesh > Bisect (Clear Inner + Fill) ou Boolean cube. Volume fermé.
Finition : Clay Strips, Scrape/Fill, Pinch ; Mirror X ; asymétrie seulement à la fin.
