# CH09.04 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le low-key n'est pas sombre | Key trop puissante | Key 70 W |
| L'ombre est grise | Fill trop forte | Fill 0,5 W |
| Le high-key est terne | Lumière insuffisante | Key 250, Fill 150 |
| Pas d'effet de couleur | Lampes blanches | Color orange / bleu-vert |
| On règle la mauvaise scène | Scène active confondue | Vérifier le sélecteur de scène |
| Rendu bruité | Peu d'échantillons | 48 minimum |
| Les lampes d'une scène éclairent l'autre | Lampes liées aux deux scènes | Une lampe par scène |
| Teintes trop proches | Écart < 120° | Orange et bleu-vert |
