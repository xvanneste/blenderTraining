emplacement des menus (Bisect : *Mesh* ; Spin : `Alt+E` ; Screw : *Edge* + modificateur
*Generate*), options de Spin, Bisect, Screw, Merge, *Limited Dissolve (Max Angle)*. Comportement de
Spin mesuré avec l'opérateur réel : Auto Merge laisse les sommets d'axe superposés.
