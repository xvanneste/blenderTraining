# CH09.08 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le sujet sort du cadre | Focale trop longue pour la distance | Recalculer f = 0,4 × (8 + c) × 20,25 / 1,8 |
| Le fond reste petit | Recul insuffisant | c ≥ 16 m |
| Sujet minuscule | Recul sans zoom | Allonger la focale |
| Le correcteur dit que les cylindres ont bougé | Objet déplacé | Ne toucher qu'à la caméra |
| Champ différent du calcul | Sensor Fit ou taille du capteur modifiés | 36 mm, Auto |
| Focale refusée | Moins de 70 mm | ≥ 70 mm |
| Mesure impossible | Cylindre hors cadre | Recadrer |
| Couleurs changées | Couleur d'objet modifiée | Rouge et vert purs |
