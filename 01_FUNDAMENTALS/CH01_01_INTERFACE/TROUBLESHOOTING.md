# CH01.01 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Un raccourci « ne fait rien » | La souris survole un autre éditeur | Placer la souris au-dessus de l'éditeur concerné |
| La barre d'outils / sidebar a disparu | `T` / `N` pressé par erreur | `T` / `N` ; ou menu *View* de l'éditeur → *Toolbar* / *Sidebar* |
| L'en-tête a disparu | Masqué via le menu contextuel | Petite flèche en haut à droite de la zone, ou `RMB` dans la zone → *Show Header* (selon éditeur), ou *View → Area → …* |
| Une zone est devenue minuscule ou a été fusionnée | Glissement accidentel depuis un coin | `Ctrl+Z` (les opérations sur l'interface s'annulent) ou recréer par division |
| L'interface entière a changé de disposition | Changement de workspace (`Ctrl+PageUp/Down`) | Cliquer l'onglet *Layout* |
| La vue 3D est en plein écran sans menus | `Ctrl+Alt+Space` | Même raccourci |
| Le panneau *Adjust Last Operation* n'apparaît plus | Il n'existe que pour la **dernière** action, et disparaît après une autre action | `F9` juste après l'action |
| Les workspaces personnels ne sont pas dans un nouveau fichier | Ils sont stockés dans le `.blend` | *File → Defaults → Save Startup File* |
