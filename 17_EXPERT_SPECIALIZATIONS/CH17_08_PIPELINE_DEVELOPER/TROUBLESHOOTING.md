# Dépannage — Pipeline Developer

**Symptôme** Le processus sort sans erreur mais manque un fichier nécessaire.

**Cause à vérifier** Le script vérifie seulement le code de retour et ignore les produits.

**Correction** Inspectez le manifeste et les fichiers avant d’autoriser la publication.

Refaites le contrôle final. Une commande refait les tests nominal et négatifs, avec code de sortie et rapport cible.
