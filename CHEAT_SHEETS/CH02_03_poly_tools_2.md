# Fiche de révision — CH02.03 Outils polygonaux II

**Knife `K`** : clic = point · `Entrée`/`Espace` valider · `Échap` annuler · clic droit = nouvelle
ligne · `Shift` (maintenu) = milieux · `Ctrl` (maintenu) = sans aimant · `A` angles · `C` à travers ·
`X/Y/Z` axe · `S` cotes · `V` profondeur · `Shift+K` sélection seule.
**Bisect** (menu Mesh) : Plane Point / Normal (local), Fill, Clear Inner/Outer.
**Spin** (`Alt+E`) : autour du curseur ; Steps, Angle, Axis, Auto Merge → puis `A`, `M` By Distance.
**Screw** : modificateur Generate (Screw, Iterations, Steps, Axis) ou opérateur (menu Edge).
**Merge `M`** : At Center, At Cursor, Collapse, At First, At Last, By Distance.
**Dissolve** (`X` / `Ctrl+X`) : Vertices, Edges, Faces, Limited Dissolve (Max Angle), Collapse,
Edge Loops. Delete troue, Dissolve simplifie.
