# CH18.03 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le personnage paraît raide | Ligne d'action absente ou droite partout | Commencer chaque pose par une courbe C ou S |
| Il semble tomber | Centre de gravité hors de l'appui | Verticale depuis le cou → la ramener sur le pied d'appui |
| Bras « en caoutchouc » | Longueur des segments variable | Mesurer l'avant-bras ; garder les mêmes longueurs |
| Silhouette illisible | Membres collés au corps, vue de face plate | Écarter les bras, tourner le personnage de trois-quarts |
| Les croquis prennent 5 minutes | Détails trop tôt | Chronomètre strict 30 s ; uniquement ligne + 3 ovales + membres |
| Le remplissage noir ne se fait pas | Contour non fermé ou matériau sans Fill | `U` → MAT_GP_Black ; fermer le contour ; outil Fill ; ou brosse très épaisse |
| Le correcteur ne compte pas mes traits | Mauvais calque actif | `Y` → calque USER_ voulu ; déplacer des traits en Edit Mode (*Move to Layer*) |
