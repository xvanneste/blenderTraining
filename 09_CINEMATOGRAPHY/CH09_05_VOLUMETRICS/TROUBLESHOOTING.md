# CH09.05 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Aucun faisceau | Density 0 | 0,08 |
| Image noire | Density trop forte | Baisser |
| Faisceau invisible | Density trop faible | Augmenter |
| Tout est éclairé | Spot trop large | 40° |
| Bruit | Peu d'échantillons | Plus d'échantillons / Denoise |
| Cube opaque | Surface dans le matériau | Volume seulement |
| Lampe visible | Ray Visibility Camera | Décocher |
| Rendu lent | Volume dense | Réduire la taille du cube |
