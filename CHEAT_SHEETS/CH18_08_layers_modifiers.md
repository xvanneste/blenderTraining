# Fiche de révision — CH18.08 Calques, modificateurs, transformations

Calque : Blend Mode (Regular, Hard Light, Add, Subtract, **Multiply**, Divide) · Opacity · Lights.
Sous-panneaux : **Masks** · **Transform** (Translation/Rotation/Scale) · Adjustments (Tint,
Stroke Thickness) · Relations (Parent, Pass Index, Use Masks in Render) · Display.
**Masque** : calque actif → Masks ☑ → + → calque masque ; masque **Opacity 0, œil ouvert**
(un masque caché n'agit plus en 5.3). Icône d'inversion par masque.

Modificateurs GP — Edit : Texture Mapping, Time Offset, Vertex Weight… · Generate : Array,
**Build**, Dot Dash, Envelope, Length, **Line Art**, Mirror, Multiple Strokes, Outline, Simplify,
Subdivide · Deform : Armature, Hook, Lattice, **Noise**, Offset, Shrinkwrap, Smooth, **Thickness** ·
Color : Hue/Saturation, Opacity, **Tint**. Influence → **Layer** / Material / Vertex Group.
Effets (onglet **Effects**) : Blur, Colorize, Flip, Glow, Pixelate, Rim, Shadow, Swirl, Wave Distortion.
Objet = tout le dessin · Calque (Transform) = une couche · Points (Edit) = la forme. Pas d'Apply.
