# Fiche de révision — CH01.04 Objets et données

Objet (transformation, modificateurs) → Données (Mesh, Camera, Light…) → Matériaux.
Nombre à côté d'un nom = utilisateurs. 0 utilisateur = supprimé à l'enregistrement (sauf Fake User 🛡).

| Action | Raccourci / menu |
|---|---|
| Ajouter | `Shift+A` |
| Supprimer | `X` / `Suppr` |
| Copie / duplication liée | `Shift+D` / `Alt+D` |
| Répéter la dernière action | `Shift+R` |
| Lier des données | `Ctrl+L` → Link Object Data |
| Rendre unique | clic sur le nombre d'utilisateurs, ou Object → Relations → Make Single User |
| Joindre (dans l'actif) | `Ctrl+J` |
| Séparer (Edit Mode) | `P` → Selection / By Material / By Loose Parts |
| Voir tous les datablocks | Outliner → Display Mode → Blender File |
| Purger | File → Clean Up → Purge Unused Data |
