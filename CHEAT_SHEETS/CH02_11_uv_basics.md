# Fiche de révision — CH02.11 UV fondamentaux

UV = coordonnées 0–1 de la texture par coin de face. Couture (Edge → Mark Seam, rouge) → îles.
Menu **`U`** : Unwrap (Angle Based / Conformal / Minimum Stretch), Smart UV Project, Cube /
Cylinder / Sphere Projection, Follow Active Quads, Lightmap Pack, Mark/Clear Seam.
UV Editor : Pack Islands (Margin), Average Islands Scale, Seams from Islands. Workspace UV Editing.
Contrôle : image générée **UV Grid / Color Grid** — déformé = étirement ; tailles différentes =
densité ; motif répété = îles superposées. Coutures cachées. `Ctrl+A` Scale avant Unwrap.
