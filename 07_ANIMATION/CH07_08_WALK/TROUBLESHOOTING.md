# CH07.08 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| Le personnage saute à chaque cycle | L'image 25 diffère de l'image 1 | Copier l'image 1 à l'image 25 |
| Les pieds patinent | Interpolation Bezier, clés trop éloignées | T > Linear ; clés tous les 2–3 images |
| Les pieds traînent | Pas de levée du pied libre | Lever d'au moins 6 cm au passage |
| La marche paraît robotique | Hanches fixes | Hanches plus basses aux contacts |
| Les bras vont avec les jambes | Bras du même côté | Inverser le balancement |
| Le pas est trop court | Jambes trop peu écartées | 0,6 m aux contacts |
| Le genou plie à l'envers | Signe de la rotation | Le genou plie vers l'avant |
| La jambe est trop longue | Cheville sous le sol | Cheville à 0,05 m |
