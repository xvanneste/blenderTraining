# Fiche de révision — CH01.01 Interface

Workspace (onglet) → zones → éditeurs → régions (header, toolbar, sidebar, tool settings).
Les raccourcis agissent **sous la souris**.

| Action | Raccourci |
|---|---|
| Toolbar / Sidebar | `T` / `N` |
| Rouvrir les paramètres de la dernière action | `F9` |
| Recherche de commande | `F3` |
| Quick Favorites | `Q` |
| Menu contextuel | `RMB` |
| Maximiser / plein écran | `Ctrl+Space` / `Ctrl+Alt+Space` |
| Workspace suivant / précédent | `Ctrl+PageDown` / `Ctrl+PageUp` |
| Ajouter (objet, nœud…) | `Shift+A` |
| Diviser / fusionner | `RMB` sur une frontière → Vertical/Horizontal Split, Join Areas |
| Changer d'éditeur | bouton Editor Type (à gauche de l'en-tête) |
