# Fiche de révision — CH04.06 Texture Painting

Mode Texture Paint → pinceau (Paint Hard) → couleur → traits sur plusieurs côtés, vue orthographique.
Image > **Pack** puis enregistrer (sinon peinture perdue). UV propres obligatoires ; rien hors des îlots.
Mesures : couverture 3–50 %, ≥ 2 couleurs, hors UV ≤ 1 %. Script : couleur de pinceau linéaire.
Correcteur : `--exercise painting [--debug]`.
