# CH08.02 — Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| La plaque tombe | Goal décoché ou Default 0 | Goal coché, Default 1, groupe pin |
| Rien ne bouge | Aucun groupe : tout est accroché | Groupe pin avec poids 0 explicites |
| La plaque s'étire | Pull/Push bas ou masse forte | 0,9 et 1 kg |
| Les sommets se dispersent | Edges décoché | Cocher Edges |
| La simulation ne démarre pas | Image courante non 1 | Retourner à l'image 1 |
| Mesure fausse | Saut direct à l'image finale | Avancer pas à pas |
| Trop lent | Trop de sommets | Grille 12 × 12 |
| Plaque fixe | Goal sur tous les sommets | Poids 0 sur les sommets libres |
